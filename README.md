# Daily Redeem

An ultra-clean, Apple-standard minimalist single-page web application for discovering and redeeming free promotional codes and vouchers for 10 popular applications.

## ✨ Features
- **Apple HIG-inspired Minimalism:** Light mode, San Francisco / Inter typography, smooth spring micro-interactions, clean cards.
- **10 Curated Applications:** Google Play Store, Amazon Pay, Flipkart, PUBG Mobile, BGMI, Free Fire, ExpressVPN, NordVPN, CyberGhost, YouTube.
- **1-Click Tap-to-Copy:** Tapping any code card instantly copies the code to your clipboard with tactile feedback and an Apple-style floating toast.
- **Zero Runtime Bloat:** Pure semantic HTML5, modern CSS3, and ES6 JavaScript. No bundler or external dependencies needed.
- **Ready for Cloudflare Pages:** Fully static architecture, deploys instantly.
